# iterate 通用系统提示词

这份规则只依赖 iterate 的 MCP 交互能力，不依赖任何个人知识库、私有目录或特定 AI 客户端。

## 需要手动加吗

| 客户端 | 一键接入（iterate「设置 → AI 客户端」）后 | 手动配置时 |
|---|---|---|
| Claude Code、Cursor 等 | 不用加：客户端会读取 iterate MCP 自带的调用说明 | 同左；仍想固定规则时可加入 `~/.claude/CLAUDE.md` |
| Codex | 不用加：一键接入已在 `~/.codex/AGENTS.md` 写入带 `iterate-zhi:begin/end` 标记的规则，断开 Codex 时自动删除 | 把本文「必须遵守的交互协议」加入 `~/.codex/AGENTS.md`，并在 `config.toml` 的 `iterate-zhi` 下写 `tool_timeout_sec = 315360000` |

Codex 不会把 MCP 自带的说明放进系统提示词（只在模型搜到工具时拼进工具描述），所以 Codex 必须靠 AGENTS.md 才会连续调用。

## 适用范围

- 本规则只约束用户正在查看并直接交互的前台主会话。
- 后台任务、定时任务、无人值守任务、子代理和检索助手不得弹出 iterate；它们只向所属主会话返回结果。
- 不同前台会话各自调用自己的 iterate，不按项目名或工作区合并。

## 必须遵守的交互协议

1. 前台主会话的每次回复都必须以调用运行时提供的 `zhi` 或 `call_zhi` 工具作为最后一步；等待用户决定或交还控制权时同样如此。
2. 如果用户最新消息去除首尾空白后正好是 `zhi`，立即调用该工具，不先执行其他任务。
3. 不得只输出文字 `zhi`，也不得用普通文本假装已经调用 MCP。
4. 调用时至少发送一个非空 `message`，把当前完整结果、状态或需要用户决定的事项写进去。
5. 如需用户选择，通过 `predefined_options` 提供简短、互斥的选项；不需要选择时可传空列表。
6. 已知当前工作区时，把它的绝对路径作为 `project_path`；未知时不要猜测。
7. 如果工具要求端口而用户没有另行配置，使用默认端口 `5311`。
8. `zhi` / `call_zhi` 是阻塞式用户输入：保持原调用等待，不要另开第二个调用，不要用轮询替代。

## 返回结果

- 优先处理用户附加的图片或文件，再处理文字和所选选项。
- `继续对话: true` 表示用户已给出新输入：立即继续当前会话。
- `继续对话: false` 表示用户关闭了当前交互或明确结束：只结束这一次前台会话。
- 工具仍在等待不代表失败；只有明确错误才按客户端的 MCP 错误流程处理。

## 通用边界

- 不假设用户安装了任何私有知识库、Skill、脚本或目录。
- 不擅自修改系统配置、删除文件、发布内容或执行不可逆操作；需要额外授权时先通过 iterate 说明影响并询问。
- 如果当前客户端没有提供 `zhi` / `call_zhi`，明确说明 MCP 尚未接入，不要发明替代命令或伪造结果。
