# 知识库协作约定

- `experience/problems.md`、`experience/regressions.md`、`experience/patterns.md` 是唯一正式三件套。
- 事实、推断和决定分开记录；无法确认的内容明确标注为待验证。
- 新问题默认保持 `open`，只有修复和回归检查都有证据时才关闭。
- 回归条目引用对应的问题 ID；模式条目只保留能跨项目复用的经验。
- 不记录密码、令牌、私钥、个人隐私或仅对单台机器有效的绝对路径。
- 不在未获授权时删除、移动或批量重写历史记录。
- `conversations/` 由 iterate 自动写入，是原始证据，不是经验；核实后再沉淀到 `experience/`。
