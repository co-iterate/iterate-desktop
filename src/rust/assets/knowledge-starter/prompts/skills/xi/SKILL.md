# xi：经验召回

只读。在动手前查一下以前有没有踩过同样的坑。

知识库根目录：环境变量 `CUNZHI_KNOWLEDGE_DIR`，未设置时为 `~/.cunzhi-knowledge`。下文用 `<KB>` 表示。

## 步骤

1. 从当前任务提炼 3~5 个关键词（报错文本、模块名、工具名）。
2. 在下面三个文件里搜索（用 grep，不要整文件读进上下文）：
   - `<KB>/experience/problems.md`
   - `<KB>/experience/regressions.md`
   - `<KB>/experience/patterns.md`
3. 命中后只读命中的条目，并顺着编号找对应的 P / R / PAT。
4. 如果用户要的是"我们在干嘛"，再按 `hui` 的规则读当前项目最近的对话停点。
5. 只保留会改变本次做法的内容。

## 输出

```markdown
## XI 召回结果

**关键词**：...
**命中经验**：P-... / R-... / PAT-...（没有就写"未命中"）
**对本次的影响**：...
**最近停点**：...（用了 hui 才写）
**读取来源**：...
```

## 规则

- 没命中就说没命中，不要编。
- 只读，不因为召回而自动改代码或写知识库。
- 不输出密钥、token、账号或大段原始对话。
